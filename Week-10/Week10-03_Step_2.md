# การชี้บ่งอันตราย
## ขั้นตอนที่ 2 การระบุผู้ที่มีความเสี่ยงและระดับความเสี่ยง


### ใครบ้างที่มีความเสี่ยงจากการปฏิบัติงาน

| กลุ่มที่ | ประเภท      | ตัวอย่าง                                                                                              |
| -------- | ----------- | ----------------------------------------------------------------------------------------------------- |
| 1        | ลูกจ้าง     | - พนักงาน (บรรจุ)<br>- ลูกจ้างประจำ                                                                   |
| 2        | ผู้รับเหมา  | - พนักงานทำความสะอาด สังกัดบริษัท<br>- แม่ค้าในโรงอาหาร<br>- พนักงานซ่อมบำรุง (ที่ไม่ใช่พนักงานประจำ) |
| 3        | บุคคลภายนอก | - พนักงานส่งสินค้า<br>- คนที่สัญจรไปมา                                                                |
| 4        | ผู้เยี่ยมชม | - นักเรียนทัศนศึกษา<br>- ตัวแทนจำหน่ายผลิตภัณฑ์ที่เข้าอบรม/ศึกษาดูงาน                                 |
|          |             |                                                                                                       |


### การระบุความเสี่ยง

1. หยิบตัวชี้บ่งอันตรายมา 1 ตัวชี้
2. ระบุว่าตัวชี้นั้นส่งผลต่อใครบ้าง
	- ระบุชื่อ หรือ ตำแหน่ง ส่วนงาน กิจกรรม
	- ถ้าเป็นไปได้ ให้ระบุจำนวนบุคคลในแต่ละกลุ่มด้วย
3. ระบุว่าผู้นั้นมีความเสี่ยงอย่างไร
4. ทยอยทำทีละข้อจนครบ
